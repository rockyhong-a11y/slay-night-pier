# SLAY: RING NIGHT

Atlas와 Nova가 맞붙는 모바일 세로 화면용 **1대1 프로레슬링 게임**입니다. 링 안에서 타격·잡기·반격을 연결하고, 로프 반동과 코너를 활용해 **3카운트 핀폴 또는 서브미션**으로 승리합니다.

**플레이:** https://rockyhong-a11y.github.io/slay-night-pier/

- **Atlas / 아틀라스**: 파워 레슬러. 파워밤·DDT·백브레이커, 코너 엘보 드롭과 타이탄 파워밤.
- **Nova / 노바**: 테크니컬 레슬러. 스플렉스·암드래그·허리케인라나, 코너 문설트와 오로라 스플렉스.
- 선택하지 않은 선수가 CPU 상대입니다. 나머지 8명은 준비 중으로 흐리게 표시되며 선택할 수 없습니다.
- 체력이 낮아질수록 커버와 관절기에서 탈출하기 어려워집니다. 체력만 소진시켜서는 경기가 끝나지 않습니다.
- 타격과 기술을 적중시켜 피니시 게이지를 채우세요. MAX에서 상대에게 접근하면 전용 피니시를 쓸 수 있습니다.

## 조작

| 행동 | 모바일 | 키보드 |
|---|---|---|
| 이동 | 왼쪽 조이스틱 | WASD / 방향키 |
| 타격 콤보 → 연속 잡기 | 타격 연타 | J |
| 차지 → 상대 뒤돌리기 | 타격을 누른 뒤 놓기 | J 홀드 후 놓기 |
| 정면 / 후면 잡기 | 가까이에서 방향 + 잡기 | 방향 + K |
| 타이밍 반격 | 상대 공격에 맞춰 반격 | L |
| 로프 달리기 / 반동 | 방향 + 로프 | Space |
| 코너 오르기 / 다이빙 | 코너 근처에서 코너 | U |
| 커버 | 누운 상대 근처에서 커버 | I |
| 서브미션 | 누운 상대 근처에서 관절기 | O |
| 피니시 | MAX에서 근접하여 피니시 | P |
| 잡힌 상태에서 탈출 | 탈출 / 타격 / 반격 연타 | E / J / L |
| 일시정지 | 상단 일시정지 | Escape |

커버 중 상대의 어깨를 3카운트까지 붙잡으면 승리합니다. 잡혔을 때는 탈출을 연타하세요. 서브미션 공격자는 관절기 버튼을 계속 눌러 압박하고, 방어자는 탈출 입력으로 저항합니다. 로프에 가까우면 로프 브레이크가 적용됩니다. 코너 기술은 오르기와 다이빙의 두 단계로 사용합니다. 달리는 중 타격은 러닝 공격으로 이어집니다.

| 방향 | Atlas 정면 | Atlas 후면 | Nova 정면 | Nova 후면 |
|---|---|---|---|---|
| ↑ | 파워밤 | 저먼 스플렉스 | 버티컬 스플렉스 | 드래곤 스플렉스 |
| ↓ | DDT | 리버스 DDT | 스냅메어 | 백 스플렉스 |
| ← | 백브레이커 | 러시안 레그 스윕 | 암드래그 | 넥브레이커 |
| → | 스파인버스터 | 불독 | 허리케인라나 | 롤링 크레이들 |

## 실행 및 검증

Node.js 22 이상을 사용하세요. GitHub Pages 배포는 Node.js 24로 빌드합니다.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
npx playwright install chromium
npm run qa:ui
npm run qa:match
npm run qa:visual
```

브라우저 검증은 Playwright Chromium을 사용합니다. `PLAYWRIGHT_BROWSERS_PATH`와 `QA_URL`로 설치 위치와 서버 URL을 지정합니다. 보고서와 스크린샷은 `artifacts/`에 저장합니다.

## 아트와 모션

원본 SD 캐릭터는 [slay](https://github.com/rockyhong-a11y/slay)와 [slay-beach-volley](https://github.com/rockyhong-a11y/slay-beach-volley)에서 가져왔습니다. 출처와 MIT 라이선스를 유지합니다.

Atlas의 승인된 Higgsfield 영상과 캐릭터별 전신 그림을 Blender에서 렌더한 12프레임 보행을 사용합니다. 이동 거리에 따라 걸음을 선택하며, 모든 전신 그림의 가로·세로 배율을 동일하게 유지합니다. 머리·몸통·다리를 별도로 늘리거나 줄이지 않습니다.

기존 28개 전투 궤적과 새 링 동작 12종은 실제 Blender에서 작성·샘플링합니다. `public/assets/motion/combat.json`과 `ring.json`이 런타임에 사용되며, 편집 가능한 `.blend`와 재생성 스크립트는 `tools/`에 있습니다. 자세와 궤적, 접촉 시점을 결합하고 펀치·킥·낙법은 같은 합성 타격음 계열을 사용합니다. 링 벨, 로프 반동, 카운트 효과음도 Web Audio로 합성합니다.

[사용자가 제공한 Rumble Roses XX 플레이 영상](https://www.youtube.com/watch?v=cra_ZRVD9Vc)의 링 중심 대결과 경기 흐름을 참고했습니다. [Konami의 Rumble Roses XX 매뉴얼](https://www.videogamemanual.com/xbox360/Rumble%20Roses%20XX.pdf)의 타격·잡기·반격, 커버, 코너 및 피니시 게이지 구성을 함께 확인했습니다. 해당 게임의 캐릭터·영상·음악은 앱 에셋에 포함하지 않습니다. 제작 이력은 [ASSET_SOURCES.md](docs/ASSET_SOURCES.md)에 기록합니다.

## 모바일 인터랙션

비편집 UI의 선택·길게 누르기 메뉴·이미지 드래그를 차단합니다. 조이스틱은 Pointer Events와 pointer capture로 이동과 공격의 동시 입력을 지원합니다. 핀치 줌, 일반 스크롤, 키보드 조작과 설정의 네이티브 폼 컨트롤은 유지합니다. 일시정지·포인터 취소·창 전환 시 눌린 공격을 발사하지 않고 취소합니다.

## 배포

`main` 푸시 시 GitHub Actions가 테스트, Vite 빌드와 GitHub Pages 배포를 실행합니다. 외부 런타임 API나 키가 필요하지 않습니다. 원본 아트와 모션 제작 파일은 저장소에 보존되며, 비활성 캐릭터의 전투 아트는 현재 경기에서 사용하지 않습니다.
